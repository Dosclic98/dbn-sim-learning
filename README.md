# dbn-sim-learning
GeNIe DBN for learning from traces generated by simulation 

## Dependency Installation

1. It is highly advised to create and activate a [python virtual environment](https://www.w3schools.com/python/python_virtualenv.asp) in wich you can install all the necessary dependencies.

2. Install pysmile from the custom index (change ```pysmile-A``` with ```pysmile-B``` if you are not using the Academic license):

```bash
python -m pip install --no-cache-dir --index-url https://support.bayesfusion.com/pysmile-A/ pysmile
```

3. Install other dependencies:

```bash
pip install -r requirements.txt
```

## Add your pysmile license

In order to run the scripts using pysmile, a license file must be provided. Every script expects to find a ```pysmile_license.py``` file (in the root directory of the project) in which you have to copy your own pysmile license.

## Create the ```plots``` and ```results``` folders

If not yet present, create a ```plots``` and ```results``` folder in the root directory of the project.

## How to paameterize the DBN

Running the ```parameterizer.ipynb``` file (or the exported version ```parameterizer.py```) it is possible to learn the CPTs of the base DBN model.
The main parameters that can be changed are:

- ```fileName```: The name of the file containing the base DBN model (by default is ```DBNfromAG.xdsl```). 
- ```outFileName```: The output file in which the parameterized DBN should be saved (by defautlt is ```DBNfromAG_learned.xdsl```). 
- ```tracesFileName```: The name of the file containing the traces used for parameterization (by default is ```dbnLogs.csv``` but there is also the ```dbnLogs100.csv``` which contains only 100 traces).
- ```numSlices```: The number of slices to consider (at the moment we are able to perform the parameterization from up to 100 slices due to a bug in pysmile)

## How to validate the trained model

After learning the CPTs it is possible to assess the DBNs performance through a k-Fold Cross-Validation (CV). Basically the validation set is split accross k equally-sized folds, k-1 are used for training and 1 is used for testing. This operation is repeated k times, every time changing the fold used for testing. The performance metrics (Accuracy, Precision, Recall, F1-score and Matthews Correlation Coefficient (MCC)) computed on each fold are then averaged to get the final results. 

During the test procedure, the nodes choosed as "target nodes" are used to evaluate the classification performance of the model, while evidence is set on the others. This means that for every trace in the test set, the values corresponding to non target nodes are provided as evidence, while the values corresponding to target nodes are compared with the model prediction (outcome with the highest likelyhood) and the confusion matrix is computed.

By default pysmile validator provide the evidence in the non-target nodes for every timeslice. Instead, in our validator, we study how providing less frequent evidence can impact the model performance. This is implemented by using a vector parameter containing all the values of ```n``` that we want to study. The k-Fold cross validation will be repeated for every value of ```n``` in the vector.

The ```validator_playground.ipynb``` (or the exported version ```validator_playground.py```) perform such operation.
The main parameters that can be tuned are:

- ```fileName```: The name of the file containing the trained DBN.
- ```dataFileName```: The name of the file containing the traces that will be used for validation.
- ```numSlices```: The number of slices to consider.
- ```ext_ev_every_n_slices```: A vector containing all the evidence-frequency values we want to study. For example if the vector contains just the value 2, it means that we just test what happens when providing evidence on the non-target nodes every 2 time slices. 
- ```algoTypeExact```: The type of algorythm to use. If ```True``` the exact algorithm will be used, otherwise the EPIS sampling algorithm will be used. At the moment the EPIS sampling algorithm cannot converge with ```ext_ev_every_n_slices``` containing 10 as a value.
- ```numFolds```: The number of folds of the k-Fold CV.
